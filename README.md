# Интернет магазин

## Описание проекта

### Это учебный проект, демонстрирующий работу по созданию интернет магазина.

Проект предоставляет базовую структуру для работы с товарами и категориями интернет-магазина. Включает поддержку типизации, тестирование и расширяемую архитектуру.

---

## Основные классы

* **`class BaseProduct`**
  - Абстрактный базовый класс для всех продуктов.
  - Содержит базовые атрибуты: название, описание, цена, количество.
  - Реализует абстрактные методы:
    - `price`: геттер и сеттер для цены.
    - `__str__`: строковое представление продукта.
    - `__add__`: сложение двух продуктов для расчета полной стоимости.
  - Обеспечивает единый интерфейс для всех продуктов и их наследников.

* **`class LoggerMixin`**
  - Миксин для логирования создания объектов.
  - Логирует создание объекта с указанием класса и переданных параметров.
  - Реализует метод `__repr__` для удобного строкового представления объекта.
  - Используется для отладки и мониторинга создания экземпляров классов.

* **`class Orderable`**
  - Абстрактный класс для заказов.
  - Реализует абстрактные методы:
    - `total_cost`: расчет общей стоимости.

* **`class Order`**
  - Наследник `Orderable`.
  - Представляет заказ на один товар.
  - Содержит атрибуты: товар, количество, итоговая стоимость.
  - Реализует методы:
    - `total_cost`: расчет общей стоимости заказа.
    - `__str__`: строковое представление заказа.

* **`class Product`**
  - Наследник `BaseProduct`.
  - Сохраняет объекты класса `Product`.
  - Содержит атрибуты: название, описание, цена, количество.
  - Реализует методы:
    - `price`: геттер и сеттер для цены с проверкой корректности значения.
    - `new_product`: класс-метод для создания нового продукта или обновления существующего.
    - `__add__`: сложение продуктов одного класса для расчета полной стоимости.

* **`class Category`**
  - Сохраняет объекты класса `Category`.
  - Содержит атрибуты: название, описание, список продуктов.
  - Реализует методы:
    - `add_product`: добавление продукта в категорию с проверкой типа.
    - `get_products`: получение списка продуктов категории.
    - `__iter__`: поддержка итерации по товарам категории через вспомогательный класс `CategoryIterator`.

* **`class Smartphone`**
  - Наследник класса `Product`.
  - Добавляет специфические атрибуты: производительность, модель, объем памяти, цвет.

* **`class LawnGrass`**
  - Наследник класса `Product`.
  - Добавляет специфические атрибуты: страна-производитель, срок прорастания, цвет.

## Дополнительные возможности

* **Поддержка типизации**
  - Код совместим с `mypy`, что обеспечивает более надежную разработку.

* **Расширенная логика сложения**
  - Метод `__add__` позволяет складывать только объекты одного класса (например, `Smartphone` с `Smartphone`).

* **Защита от некорректного добавления продуктов**
  - Метод `add_product` проверяет, что добавляемый объект является экземпляром класса `Product` или его наследников.

* **Итерация по товарам категории**
  - Реализован вспомогательный класс `CategoryIterator`, позволяющий перебирать товары категории в цикле `for`.

## Описание нового функционала

1. **Сложение товаров**
   - Реализован метод `__add__` для класса `Product` и его наследников.
   - Позволяет рассчитывать полную стоимость товаров на складе, учитывая их цену и количество.
   - Поддерживается только сложение объектов одного класса (например, `Smartphone` с `Smartphone`).

2. **Добавление товаров в категорию**
   - Метод `add_product` проверяет, что добавляемый объект является экземпляром класса `Product` или его наследников.
   - Предотвращает добавление некорректных объектов.

3. **Итерация по товарам категории**
   - Реализован вспомогательный класс `CategoryIterator`, который позволяет перебирать товары категории в цикле `for`.

4. **Новые классы товаров**
   - Добавлены классы `Smartphone` и `LawnGrass` с уникальными атрибутами, соответствующими их специфике.

5. **Класс `Order`**
   - Представляет заказ на один товар.
   - Хранит информацию о купленном товаре, его количестве и итоговой стоимости.
   - Реализует метод `total_cost` для расчета общей стоимости заказа.

6. **Абстрактный класс `BaseProduct`**
   - Объединяет общие свойства и методы для всех продуктов.
   - Содержит абстрактные методы `price`, `__str__` и `__add__`, которые должны быть реализованы в дочерних классах.

7. **Миксин `LoggerMixin`**
   - Логирует создание объектов с указанием класса и параметров.
   - Помогает отслеживать создание экземпляров классов для отладки и анализа.

## Для тестирования разнообразного поведения входных данных добавлены тесты.

* В модуле `test_main` происходит тестирование классов `Product` и `Category`,
